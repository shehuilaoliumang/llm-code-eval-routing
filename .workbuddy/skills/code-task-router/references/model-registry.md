### 关键实测结论

1. **`qwen3.7-flash` 是 L1~L3 的性价比之王**：质量 92~93 分（达标率 98.6%），单次成本仅 ¥0.0003~0.0005，比旗舰便宜 30~50 倍，S_value 在 L1/L2/L3 全部排名第一。
2. **L4 是唯一需要旗舰的难度**：`qwen3-coder-flash`（T1 代码专项）在 L4 掉到 78 分（功能分 73.3，代码真的写不对），旗舰 91~92 分不可替代。轻量模型虽过 85 线但功能分（94 左右）与旗舰（95~99.5）仍有差距，质量敏感场景需旗舰兜底。
3. **代码专项模型的"专项溢价"未兑现**：方舟 `code-preview` 在 L3（87.8）反低于 `qwen3.7-flash`（92.2），百炼 `coder-flash` 在 L4 掉队——代码专项定位在中低难度无优势、在高难度不如旗舰。
