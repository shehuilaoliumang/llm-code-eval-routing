> **数据层文件**：与 model-registry.md 同步更新。本版以 1152 次全量实测的分难度质量/成本/时延数据，
> 替换 v0.3 的先验规则。评测口径 v1.3（权重 0.10/0.45/0.20/0.25，及格线 85，裁判官方 Pro）。

## 难度分级标准

| 等级 | 核心特征 | 典型场景 |
|---|---|---|
| L1 入门级 | 单函数、短代码、常见API、无复杂逻辑 | 数组去重、格式转换、简单正则、字符串处理 |
| L2 进阶级 | 多函数协作、完整类/模块、中等算法、基础业务逻辑 | 链表CRUD、计算器类封装、单接口CRUD、状态机 |
| L3 高级 | 复杂算法、系统设计片段、调试重构、多模块 | 图算法、滑动窗口、单调栈、限流器、拓扑排序 |
| L4 专家级 | 框架级代码、疑难算法、性能敏感、复杂业务 | 最大流/费用流、KMP、Dijkstra、对顶堆、复杂撮合 |

| 输入 >32K | 按实际阶梯价重算 S_value 后排序 | — | 跳档改变成本结构，默认档近似会失真 |
| 隐私 = 仅本地 | **拒绝分派**，返回明确提示 | — | 当前无本地部署模型，不可静默降级到公有云 |

> 调用方舟模型必须用精确版本 ID（plain name 报 404 InvalidEndpointOrModel.NotFound）；
> 所有调用必须关闭思考链（方舟 `thinking:{type:disabled}`，百炼 `chat_template_kwargs.enable_thinking=false`）。

**低置信度保守策略**：分类置信度 < 0.7 时难度升一档（L2按L3选候选）。依据：分类误差代价非对称——高派一级只浪费钱（可量化），低派一级导致质量返工（代价高且难量化）。

### L4 旗舰选择的特别说明

L4 的 S_value 排名中，轻量模型（mini/flash）因成本极低排在前列，但这是**性价比公式天然偏向便宜模型的假象**。L4 属质量敏感场景：轻量模型功能分 94~95 与旗舰 95~99.5 存在实质差距（尤其 `qwen3.8-max` 功能分 99.5），专家级代码"写错一处"的返工成本远高于 API 价差。故 L4 直接指定旗舰，不套 S_value 排序——这正是"质量门槛优先于成本"原则在最高难度上的落地。

## 回退协议（四层防御）

| 层 | 触发条件 | 动作 |
|---|---|---|
| L1 质量回退（主链） | 未过语法检查/单元测试 | 备选链下一模型重试，回传上次失败信息 |
| L2 连续失败升级 | 连续2个模型失败 | 跳过排序直接调用旗舰（`qwen3.8-max` 或 `doubao-seed-2.1-pro`） |
| L3 平台故障转移 | 平台5xx/限流/超时 | 切换另一平台同梯队模型 |
| L4 预算熔断 | 日累计成本达上限 | 暂停付费调用，仅用免费额度内模型或告警 |

隐性成本规则：失败任务实际成本 = 链上全部尝试成本之和；备选链长度 ≤ 3；监控「首选命中率」（目标 ≥ 80%）。

统一启用判据：`期望质量增益 × 任务价值 > 增量成本`。并行落选结果同样计费，成本按满额2×计。

## 排序公式（实测数据已就位，S_value 可启用）

```text
S_value = S_quality / (Cost^α × Time^β)
```

- 默认 α=0.65（成本敏感系数）、β=0.25（时延敏感系数）
- 成本敏感场景：α=0.8、β=0.15；时延敏感场景：α=0.4、β=0.4
- Cost 按实测单次成本（元）；Time 为实测平均耗时（秒）
- **注意**：L4 不套 S_value 排序，直接指定旗舰（见上文特别说明）
