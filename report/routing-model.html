两步筛选法

先看「能不能干」，再看「谁最划算」——质量门槛一票否决，性价比排序择优。
第一步 · 质量门槛
S_quality = 0.10×语法 + 0.45×功能 + 0.20×规范 + 0.25×健壮
语法 10% 自动 功能 45% 单测 规范 20% 裁判 健壮 25% 裁判
及格线：L1~L4 统一 = 85，未达标即淘汰（实测质量分布的自然断裂点）。
第二步 · 性价比排序
S_value = S_quality / ( Costα × Timeβ )
α 成本敏感 0.65 β 时延敏感 0.25
成本敏感 α=0.8/β=0.15 · 均衡 0.65/0.25 · 时延敏感 0.4/0.4。

四步决策

任务进入后的完整处理链路，三层解耦、独立可替换。
① 难度分类
T3 轻量模型判断 L1~L4 + 置信度，成本 < 0.001 元/次
② 候选筛选
硬约束过滤 → 质量门槛（S_quality ≥ 85）
③ 性价比排序
S_value 从高到低排，确定首选与备选链（L4 直接旗舰）
④ 分派执行
Top1 首选，Top2/3 备选；失败进入回退链

五层回退

首选失败时逐级兜底，保证端到端成功率 ≥ 95%。
层级触发条件动作
L1 质量回退代码未过语法 / 单测按备选链下一模型重试，携带上次失败信息
L2 连续失败升级连续 2 个模型失败跳过排序，直接升旗舰（qwen3.8-max / pro）
L3 平台故障转移平台 5xx / 限流 / 超时切另一平台同梯队模型
L4 高负载降级并发请求过大临时优先响应更快的模型
L5 预算熔断日累计成本到上限暂停付费调用，告警等待
